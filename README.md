magic file box 是一个 Windows 本地文件预览工具。把 PDF、Word、Excel、PPT、文本或图片拖进窗口，就能开始阅读；多个文件可以放在同一窗口的标签里，也可以并排打开。

文件在本机解析，不上传，不改写打开的源文件。需要修改表格时，主动进入“编辑副本”，完成后另存；PDF 的高亮与备注留在当前会话，也可以把当前页批注导出为 PNG。

## 适合你吗？

- 想直接查看文档和表格，不想为了预览额外安装 Office。
- 经常同时打开几份文件，需要标签切换、并排阅读、查询或批量打印。
- 想阅读 Markdown 和代码，或对表格做常用修改后保存一份副本。

如果你需要完整的 Office 编辑、复杂 Excel 计算或严格还原所有排版，请继续使用相应的专业软件。magic file box 侧重本地预览与常用操作。

## 快速开始

安装包来自当前仓库的公开 Release；Windows 安装版可通过设置中的更新入口检查后续版本。

1. **安装。** 从 [1.0.13 Release](https://github.com/Linn924/magic-file-box/releases/tag/v1.0.13) 下载 `MagicFileBox-Setup-1.0.13-x64.exe` 并安装。无需 Office 或其他预览软件。
2. **打开文件。** 拖入文件、点击打开入口，或按 `Ctrl+O`。安装后也可在资源管理器的“打开方式”中选择 magic file box；是否设为默认程序由你决定。
3. **开始阅读。** 多文件打开时选择标签或独立窗口。悬停图标可查看用途；查询使用独立浮窗，放大、适配和全屏操作留在阅读工具栏。

安装包目前未做代码签名，Windows SmartScreen 可能提示未知发布者；请从本仓库的 [Releases](https://github.com/Linn924/magic-file-box/releases) 下载。

## 功能

### 文件与窗口

多个文件可以在同一窗口中切换，也可以各用一个窗口。标签支持拖动排序、关闭、悬停查看完整名称，以及跨预览窗口拖拽合并。标签溢出时可横向滚动，打开与设置按钮保持可见；标签栏滚轮、内容滚到边界后继续滚动可切换文件。

预览窗口可默认最大化。关闭预览窗口只关闭该窗口；首页可选择询问、退出或隐藏到托盘，并记住选择。隐藏首页后，已有预览窗口仍可使用；托盘可恢复窗口或退出软件。未保存的 Excel 修改会在关闭或退出时提示处理。

打开文件时也可将主页隐藏到托盘，默认每次询问；可在确认框记住选择，或在设置中改为“始终隐藏”“不隐藏”。该设置与关闭首页的行为独立。主页已隐藏、取消选择文件或文件未通过初始读取检查时，不再询问隐藏主页。

### 阅读与外观

- 文件加载期间，预览内容区中央显示读取、等待解析、解析及准备显示阶段；耗时较长时显示已用时间，不显示估算百分比。可取消加载，保留标签并重新加载；失败后也可重试。PDF 输入密码时保留可操作的密码界面。
- 普通表格在本机后台解析，多个窗口依次处理，取消时终止对应任务。大文件自动使用按需预览，保留读取、解压、图片和并发预算。
- 分页文档连续滚动，页码跟随阅读；上一页、下一页和输入页码用于定位。
- 缩放支持 **25%–400%**。支持适配的格式可选择适合宽度或整页适配，保持内容比例。
- `F11` 切换沉浸全屏，`Esc` 退出；进入时保持已选显示模式和倍率，边角可唤出工具栏与页码，退出后恢复进入前的阅读选择。
- 白天、黑夜或跟随系统主题。窄窗口工具栏按功能组换行，图标悬停显示用途。
- PDF、Excel 和文本的查询使用可拖动浮窗，打开后聚焦输入；关闭回到入口，各文件的查询互不覆盖。

### PDF：阅读、查询与会话批注

**阅读导航。** 支持文字选择与复制、目录过滤与折叠、当前章节高亮、文档内部链接、缩略图三档尺寸和可调整的导航栏宽度。目录可定位到页内章节，同一页的多个标题分别跳转；滚动正文时按章节位置同步选中项，缩放、双页及旋转后仍按目标坐标定位。目录搜索栏固定在条目滚动区域上方；三角箭头向右表示收起、向下表示展开，同级标题对齐。目录标题单行显示，超出宽度用省略号表示，悬停可查看完整标题，页码保持可见。缩略图按页面比例显示，点击可跳页；长列表按需绘制，滚动返回时重新绘制已释放的缩略图。密码仅留在当前文件会话中，打印遵守 PDF 权限。

**自动双页。** 页面按 1–2、3–4 配对，奇数末页居中。缩小到可以并排时显示双页，放大后恢复单页；窗口、侧栏和旋转变化也会重新判断。混合尺寸可同时显示单页与双页，切换保留原始页码与阅读位置，不强行改变倍率。

目录书签坐标不准确或父子章节共用坐标时，会用目标页中唯一匹配的完整标题校正，点击后将标题放到阅读区顶部附近；滚动同步也使用校正位置。短尾页无法滚到顶部时，仍选中该页对应章节。扫描页、标题无法确认或同页有多个相同标题时，沿用 PDF 原书签位置；无法解析的文档内部链接保留当前阅读位置。HTTP/HTTPS 网页链接可主动交给系统浏览器打开，PDF 中的脚本不执行。

**全文查询。** 支持区分大小写、普通文字、通配符和正则，以及命中定位。`?` 匹配一个字符，`*` 匹配同一行内任意字符；正则采用 JavaScript Unicode 语义，忽略零长度命中。疑似扫描件会提示没有可提取文字，目前不提供 OCR。

**临时批注。** 选择文字后，在选区旁添加高亮或备注；批注列表支持跳页、编辑备注和删除。批注不写回 PDF，关闭文件后清空。可主动将当前页与批注合成为 PNG，备注排列在页边；跨页选区不合并为一条批注。

**演示与平移。** 演示使用黑底、单页整页适配，退出后恢复原视图；演示、打印和 PNG 导出仍按原始页面处理。放大后可按住空格并用左键拖动，或用中键拖动平移。

### Word：DOCX 搜索与标题目录

DOCX 支持 `Ctrl+F` 或工具栏入口打开查找浮窗，搜索已渲染的正文、表格、页眉页脚和脚注文字。匹配可跨同一段落内的加粗、斜体等文字片段，显示当前项/总数；输入后自动定位首项，可通过上一处/下一处或 `Enter` / `Shift+Enter` 循环定位，当前命中有独立高亮。清空或关闭查找会移除搜索标记。

标题目录依据 DOCX 的段落大纲级别、标题样式及样式继承生成，按层级排列；点击标题跳转，滚动正文同步标记当前章节，同名标题分别保留。目录开关保留在当前文件会话中，关闭文件后清空。未设置标题样式或大纲级别的文档会显示空目录提示。

搜索不包含图片中的文字，不跨段落拼接匹配；目录不根据字号或加粗猜测标题。搜索与目录只作用于预览，不修改源文件。旧版 DOC 暂未提供这两个入口。

### Excel：预览，然后编辑副本

默认打开时只预览。点击铅笔图标才开始编辑，切回预览仍保留本次草稿。工作表标签位于底部，支持宽表横向查看、地址定位（如 `B12`）与固定表头/行号；预览列宽只是本次阅读设置。

| 操作 | 已支持内容 |
| --- | --- |
| 单元格编辑 | 双击或 `F2` 输入文本、数字和公式；清空、矩形粘贴、撤销/重做、恢复源内容；单引号强制文本，超过 15 位的整数按文本保留 |
| 区域选择 | 鼠标拖选、Shift 扩选、方向键扩选、整行/整列与全选；合并区域完整纳入，拖到边缘自动滚动 |
| 单元格格式 | 字体、字号、粗斜体、下划线、删除线、文字/填充颜色、边框范围/线型/颜色、水平/垂直对齐、换行、缩进、文字旋转、数字/文本/货币/百分比/日期格式；混合属性标明，未修改属性保持原值 |
| 行列管理 | 上下插行、左右插列、删除整行/列、自定义数量（1–1000）；支持的引用、普通样式、合并与图片锚点随位置调整 |
| 行列布局 | 拖动或数值设置行高/列宽、自动适应、隐藏与取消隐藏所选行列或全部行列；预览尺寸与编辑尺寸分别处理 |
| 合并单元格 | 合并、合并居中、取消合并；多格有内容时先确认保留哪一格，默认取消，撤销可恢复 |
| 区域剪贴板 | 复制、剪切、常规/值/内容与公式/格式粘贴、格式刷；复制调整相对与绝对引用，剪切成功后才清空来源；覆盖先确认 |
| 填充 | 向下/向右拖动填充柄、指定范围填充；两格数字按差值，日期按日递增，普通数字/文本重复，公式引用随位置调整 |
| 查找替换 | 当前表或固定选区、显示内容或表达式/原始值、大小写与整格匹配、命中计数与上一/下一格；编辑模式可单个/全部替换，公式重新校验 |
| 公式辅助 | ƒx 函数参数窗口、输入自动补全与参数提示、点选/拖选引用、跨表引用及引用范围高亮；Σ 自动求和，不覆盖已有结果格 |
| 工作表管理 | 新建、重命名、复制、删除、调整顺序、隐藏与取消隐藏（含原有深度隐藏表）；名称校验、删除影响确认、最后一表/最后可见表保护 |
| 排序 | 明确区域及标题行，升序/降序、最多八列优先级；保持同行内容、公式、样式、行高和手动隐藏关联，相同键保持原顺序 |
| 筛选 | 按显示值或空值筛选，多值为“或”、多列为“且”；清除筛选恢复视图并保留手动隐藏，支持撤销/重做 |
| 复制与文本导出范围 | 全部行（含隐藏行）或仅可见行；仅可见行复制显示值，不含公式/格式，也不执行剪切；CSV/TSV 可导出可见行，Excel 副本始终保留全部行 |

编辑时 `Enter` 提交并向下，`Tab` / `Shift+Tab` 左右移动，`Alt+Enter` 换行，`Esc` 取消当前输入。普通移动只在目标超出视口时少量滚动；中文输入法确认不提前提交。内容栏可定位、确认/取消和输入公式，右键菜单提供常用操作。编辑框保留自身的文字选择与撤销行为。

**十二个常用公式实时计算：** `VLOOKUP`、`ROUND`、`ROUNDUP`、`ROUNDDOWN`、`SUM`、`AVERAGE`、`MIN`、`MAX`、`COUNT`、`COUNTA`、`ABS`、`IF`。支持同工作簿跨表、区域与绝对引用，以及运算、比较、百分比和文本连接。修改引用值、撤销/重做或调整结构后更新结果；内容栏保留公式，单元格显示结果。未支持的公式显示表达式与说明，不使用过期结果；循环、超限与计算错误明确显示。

`VLOOKUP` 精确匹配支持文本通配符，近似匹配要求首列升序；`ROUND` 支持正负小数位，负数中点远离零舍入。自动求和在多行选区的各列下方、单行选区的右侧写入，空白单格识别上方或左侧连续数值；合并、超限或结果位置已有内容时拒绝。

**整表复制与区域复制不同。** 工作表复制保留普通 XLSX 内容、样式、尺寸、隐藏、合并、图片、超链接与备注，并将复制表的本表引用指向新表；重命名同步支持的跨表引用，删除后的引用显示 `#REF!`。区域复制包含内容、公式、常见样式与合并，不包含图片、超链接、备注或规则对象。跨工作簿可复制，剪切移动仅限同一工作簿。

**保存需要你主动选择位置。** XLS 默认另存整份 XLS，也可选择 XLSX；其他来源可保存 XLSX，或将当前表另存 UTF-8 CSV/TSV。CSV/TSV 不承载样式、其他表和公式，含公式或新编辑格式时应选择 Excel 副本；保存单表不会将其他表或工作表管理标记为已保存。公式形态文本会加文本前缀。

XLSX 保留未修改的载荷，内容修改更新支持的公式结果并请求外部软件重算。XLS 保留支持的公式、常见格式、布局和日期系统；旧式对象、宏、条件规则、验证、富文本或复杂样式可能无法完整保留，另存前按实际检测提示，确认后才继续。XLS 的 56 色调色板超出时提示近似颜色；不支持的公式或格式上限不会静默转为数值保存。

每次区域或结构操作整体撤销，失败不部分修改。无法安全调整的复杂公式、共享/数组公式、命名区域、外链、图表、透视表、保护或规则对象会在相关操作前拒绝。保存取消或失败保留草稿；草稿、待提交输入与历史可随标签卸载和窗口移交恢复，关闭文件后清空，无自动保存或崩溃恢复。副本不替换本次源文件，恢复源内容始终回到最初打开的数据。

`A3:A1` 等反向范围与正向范围采用相同的安全检查；整段移动与插删行列后保留端点顺序和绝对引用标记，无法安全调整的部分范围剪切会整体拒绝。大工作簿切换工作表时从首列显示，当前表的行、列组与工作表标识可随会话恢复。

**排序与筛选的边界。** 排序必须覆盖所选数据行的全部非空列，标题可排除；数字和日期按数值比较，随后是文本、布尔和错误，降序反转，空值始终放在最后。引用随被移动的单元格调整，绝对引用也遵循区域移动规则；引用变成不连续区域、数据区含合并，或目标表含图片/备注/特殊对象时拒绝排序。活动筛选需先清除，才能排序或插删行列。

筛选只改行的可见状态，编辑内容后可重新应用。XLSX 副本保存条件及区分隐藏来源所需的文档内元数据，保存重开、撤销与移交后仍可正确清除；含本次活动筛选的 XLS 输出会明确要求选择 XLSX，清除后仍可另存 XLS。CSV/TSV 不保存条件，选择仅可见行不会把完整草稿标记为已保存。原有高级筛选或无法确认隐藏来源的筛选需先在表格软件中清除再打开，避免误取消手动隐藏。

### Markdown、文本与代码

**源码阅读。** 行号、查询高亮、UTF-8 / GB18030 / UTF-16 LE / BE 编码切换；JSON 可格式化，无效内容会提示。长文本按可见行显示，换行、字体与缩放变化保留阅读位置；高亮不改变原始字符或空行，复制得到原文。

工具栏或 `Ctrl+G` 可跳转到显示文本的指定行；JSON 按格式化后的行号定位，Markdown 需切到源码模式。支持按语法识别代码块、注释、标记标签及 Python/YAML 缩进结构，逐块或全部折叠/展开，保留原始行号；跳行与搜索会展开目标所在的折叠区域。折叠状态只留在文件会话中，编码变化后重置；未知语言、语法识别失败或超出语法预算时保留完整展开文本。按需读取的大文本继续使用记录定位。

Markdown 源码中的代码示例可整体折叠，围栏内的标题保持为示例内容；未闭合的代码围栏延伸至文末。

JSON、文本与代码搜索会定位到首个命中，显示当前项/总匹配数，并标记当前命中；同一行的多处匹配分别计数。可用上一处/下一处按钮或 `Enter` / `Shift+Enter` 循环定位，长文本中的未显示行也可直接跳转。清空或关闭搜索会移除高亮。

源码查询在输入短暂停顿后分批处理，新查询、编码切换或关闭文件会取消旧任务。重复匹配很多的行限制高亮数量，当前命中仍会显示，完整计数与上一处/下一处定位不受影响；界面会提示部分高亮。

**本地语法高亮。** 识别关键字、函数、类型、字符串、数字与注释，支持跨行状态、Vue 等内嵌语言和 Markdown 标注语言的代码块。配色跟随明暗主题，未知语言、超大文件或处理失败时保留纯文本。代码只用于阅读，不执行，也不提供编译或语义诊断。

**Markdown 排版。** 支持表格、引用、代码块、标题目录、只读任务列表、脚注、KaTeX 数学公式与 Mermaid 流程/时序图。目录可定位当前章节，长目录滚动或键盘可达；脚注可往返，代码块和图表源码可复制。可切换原始源码，阅读模式与目录开关保留在当前会话。

**链接与图片。** 本页/跨 Markdown 锚点可跳转，本机相对路径、绝对路径与 `file:` 链接遵循多文件打开设置；支持中文、空格与 URL 编码。HTTP/HTTPS 链接由你点击后交给系统浏览器；不执行程序链接，不支持网络共享路径或本地链接查询参数。图片靠近视口时才在内存读取，SVG 清理主动内容；不自动加载网络图片，源码切换或关闭时释放。无效图片、公式或图表保留提示或源码。

排版模式查询可跨加粗等行内格式匹配正文、表格、脚注与可见代码，显示计数并用 `Enter` / `Shift+Enter` 或按钮定位；关闭清除高亮。公式排版与图表内部文字不计入正文查询，可切到源码查找其表达式。图表主题重绘保持搜索命中与阅读位置。

**代码外观自定义。** 在设置中分别编辑白天/黑夜的文字、背景、行号、各类语法和搜索标记颜色，设置粗体、斜体、下划线与本机字体，选择默认、柔和或高对比预设。修改即时预览，明确保存后同步窗口；支持逐项/全部恢复、取消与失败重试。自定义 CSS 只作用于代码区域，可调整颜色、字体、文字装饰、边框颜色与 Tab 宽度，不加载外部样式或字体。

```css
.comment { color: #667085; font-style: italic; }
.dark .keyword { font-weight: bold; }
```

### Word、PowerPoint 与图片

Word 可查看文字、图片、表格与分页；临时拖动表格列宽不修改文件，标签闲置后仍保留。DOCX 可打印，旧 DOC 的排版还原较弱。

PowerPoint 可连续查看幻灯片，按页码跳转。文字与图片等静态布局与应用主题隔离；复杂字体、图形、SmartArt 或动画不保证完整还原。

图片支持适配和原始像素查看，EXIF 旋转/镜像方向自动纠正一次。手动旋转后按新宽高适配，大图可从原点滚动查看；标签卸载保留本次旋转与原始像素选择，关闭后清空。尺寸与倍率/适配状态显示在页脚。

“图片信息”查看格式、大小、预览尺寸及可读取的常见 EXIF 字段，包括相机、镜头、拍摄时间、曝光、光圈、ISO、方向与 GPS（若文件包含）。颜色取样开启后点击图片，显示 HEX、RGB、透明度及像素坐标；颜色值可选择复制，`Esc` 退出取样。缩放、适配和手动旋转后仍按点击位置取色；大图片取自缩小预览，会标明“预览像素”。信息和取样只保留在内存中，不修改源文件。

曝光时间按元数据数值显示，可使用 `1/125 s` 或 `0.75 s` 等形式。

### 单文件与批量打印

支持 **PDF、图片与 DOCX**。打印设置是独立窗口，可与预览并排、移动到另一显示器；多个文件汇入同一列表，支持添加、拖入、勾选、排序、移除与折叠设置。点击文件名可联动预览，原预览关闭后可重建。

| 设置 | 可选内容 |
| --- | --- |
| 打印机 | 本批次共用；可打开系统打印机与队列 |
| 纸张 | A3、A4、A5、A6、Letter、Legal |
| 方向与份数 | 横向/纵向，1–99 份 |
| 页码与页序 | 范围如 `1-3,5`；顺序、逆序、奇数页、偶数页 |
| 颜色与双面 | 黑白/彩色，单面/双面，取决于打印机支持 |
| 缩放 | 适合纸张、实际大小、仅缩小 |

每个文件独立设置参数，也可将当前设置复制给全部文件后分别调整。展开时显示所选纸张、方向、缩放方式与排版示意；可编辑控件使用独立输入底色，聚焦时强调边框，打印期间禁用的控件显示灰底。PDF“实际大小”不自动缩小，超出可打印区域时居中裁切；屏幕缩放与打印缩放分别处理。

启动后冻结本批次参数并顺序提交，显示进度与逐文件状态；单项失败可重试或继续。可停止后续任务，已进入系统队列的任务无法在应用内撤回；打印期间新加入的文件等待当前批次结束。关闭打印窗口释放本次列表与设置。

“已提交”表示系统接受任务，不代表已经出纸；纸盒、纸张、彩色与双面受驱动和设备配置影响。当前示意以首页为主，不提供逐页纸张预览、发票识别或多张发票拼版。DOC、Excel、PPT 和纯文本暂不支持打印。

### 设置与软件更新

设置弹窗按外观、窗口与文件、打印、软件更新、专属服务分组。左侧点击分组可将右侧滚动到对应组首，右侧连续展示全部设置，滚动时左侧高亮同步更新。标题、分组导航和底部说明保持可见，设置内容独立滚动。

| 设置 | 可选内容 |
| --- | --- |
| 外观 | 白天、黑夜、跟随系统；独立的代码高亮外观自定义 |
| 关闭首页 | 每次询问、退出软件、隐藏到托盘 |
| 打开文件时隐藏主页到托盘 | 每次询问（默认）、始终隐藏、不隐藏 |
| 多文件打开 | 询问、一个窗口用标签、每个文件一个窗口 |
| 默认缩放 | 50%、75%、100%、125%、150%、200% |
| 预览窗口 | 默认最大化开关 |
| 打印入口 | 本窗口全部可打印文件、仅当前文件、不自动加入 |
| 软件更新 | 启动检查开关、手动检查、下载、取消/重试与重启更新 |

更新功能支持 Windows 安装版启动后后台检查，也可在设置中手动检查。发现新版只提示，点击后才下载；下载包校验通过后可选择重启更新，保留应用设置。更新说明按分行文字显示，保留列表条目与换行，不显示 HTML 排版标签。关闭设置后，“当前已是最新版本”的临时提示清空，重新打开时不残留。多个窗口共用检查，提示避开设置和沉浸阅读，普通退出不自动安装。源码启动与免安装版本不执行自动安装更新。

重启前检查各窗口：未保存的 Excel 修改需先处理，编辑、另存、导出、打印或窗口移交进行中暂不重启。有 PDF 会话批注时提示清空，确认默认取消；取消或失败保留当前会话。发布源码不会更新已经安装的软件。

## 隐私与文件安全

- **文件只在本机处理。** 预览无需服务端，不上传文档或源路径，不保存最近文件与路径历史。
- **打开的源文件保持原样。** 调整阅读视图不会改文件；Excel 副本与批注 PNG 只有主动选择保存位置后才写入，不覆盖已打开的源文件及其路径别名/硬链接。
- **阅读会话不自动落盘。** 密码、批注、Excel 草稿、文件引用和预览缓存仅在内存中，关闭后释放，不自动生成预览副本或转换产物。
- **应用偏好可以保存。** 主题、窗口行为和明确保存的代码外观等设置会保留，不包含源文件、搜索词或阅读历史。
- **联网有明确用途。** 更新检查和下载使用固定 GitHub 渠道，更新包与校验缓存可落盘；网页链接只有点击后才交给系统浏览器。Markdown 不自动下载网络图片。
- **打印由系统接管。** Windows 和打印机驱动可能保存系统打印缓存，这部分由系统管理。

## 兼容性与资源限制

支持按需读取的格式不再因超过原来的 5 MB / 100 MB 门槛直接拒绝。文件大小、内部结构及图片像素决定采用哪种预览方式；可尝试打开几百 MB 文件，实际可读范围仍受资源预算约束。

| 大文件类型 | 按需预览方式与边界 |
| --- | --- |
| 文本、日志、代码、JSON、Markdown | 超过 4 MiB 后按记录分块读取，支持编码切换、前后翻段、位置跳转及查找；JSON 保持原文，Markdown 与代码不生成整篇排版/语法高亮。超长行拆成显示段，仍标明原行号。 |
| CSV、TSV | 超过 8 MiB 后按记录和列组查看，支持引号、跨行字段与文本标识符；查找当前列组，不提供编辑或导出。 |
| XLSX | 超过 24 MiB 后选择工作表读取单元格值，省略不存在的空白行；公式显示文件中已有的缓存值，不重新计算。不还原完整样式、合并布局、图表和图片，不提供编辑、另存或打印。 |
| DOCX | 超过 24 MiB 后按段落读取正文与标题，图片靠近阅读区域才加载；表格按文字顺序显示。不还原原分页、复杂版式、页眉页脚和脚注，也不提供完整目录及打印。 |
| PPTX | 超过 24 MiB 后按幻灯片读取文字及按需图片；不还原对象坐标、动画、音视频和母版背景。 |
| PDF | 超过 16 MiB 后按所需字节范围读取，继续使用页面虚拟渲染、搜索与导航；读取预算耗尽时可重新加载，不提供此模式的打印入口。 |
| 图片 | 超过 8 MiB 或 600 万像素后显示最多 600 万像素的缩小图，保留缩放和旋转。仍需浏览器读取图像流并解码，不能保证所有大图片都能打开；超过 6400 万像素时拒绝解码。大型 SVG 按源码查看。 |

大文件查找与首次跳到较远位置需要扫描前面的内容，期间可取消；文本稀疏索引仅保留在当前内存会话。大文件标签闲置、关闭、移交或窗口重载时释放读取任务，重新进入可恢复本次会话中的逻辑位置。源文件被其他程序修改时停止读取并提示重新打开，避免拼接不同版本的内容。

复杂 Office 排版、缺失字体、旧格式、图表或特殊对象可能无法完整还原。Excel 提供常用编辑、排序筛选与十二个函数，不提供完整计算引擎、外部工作簿计算、动态数组或图片/超链接/备注的新增编辑。PDF 暂无 OCR，旧版 DOC 和 PPT 暂无全文查询。

文件按需读取，闲置标签释放预览内容；PDF、表格和长文本按可见范围渲染。没有人为限制多选数量，但能同时处理多少文件仍受电脑内存和文件复杂度影响。高倍率 PDF 可能降低预览像素以控制画布占用，页面比例保持，打印分辨率独立处理。
