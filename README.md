# File Preview（文件预览）

版本：3.3.5 · 文档更新：2026-10-10

Windows 10 / 11 x64 本地文件预览工具，Electron + Vue 3 + TypeScript，无服务端，无需安装 Office。文件不上传、不修改源文件，不自动保存预览副本、转换产物或路径历史；仅保存明确选择的应用设置。PDF 批注、密码、Excel 编辑草稿和文件引用只留在内存会话；批注 PNG 和 Excel 副本仅在用户主动选择保存位置时另存。

仓库：[Linn924/filePreview](https://github.com/Linn924/filePreview)

文档入口：[更新记录](docs/更新.md) · [项目规范](docs/规范.md) · [开发入口](AGENTS.md)

## 打开文件与窗口

- 支持选择文件、拖拽文件、`Ctrl+O` 和工具栏「+ 打开」；显示文件名和大小。
- 安装后可通过资源管理器「打开方式」使用本软件打开文件；默认关联由用户自行选择。
- 多文件可在同一个窗口内用标签切换，也可分别打开窗口；首次询问，后续可在设置中修改。没有人为限制多选文件数量。
- 标签支持关闭、拖动排序、悬停查看完整文件名，以及跨预览窗口拖拽合并。
- 标签未溢出时，“+”紧跟最后一个文件；溢出时，“+”固定在标签区右侧，设置齿轮始终固定在最右侧。横向滚动条单独预留高度，不挤压标签文字，不出现标签栏纵向滚动条。
- 标签栏滚轮支持切换文件；内容滚到顶端或底端后继续滚动也可切换文件。
- 预览窗口可默认最大化。关闭预览窗口直接关闭该窗口；关闭首页可选择退出软件或隐藏到托盘，并记住选择。
- 托盘支持恢复窗口和退出软件。

## 阅读与外观

- 分页文档连续滚动阅读，当前页码跟随滚动；上一页、下一页和输入页码用于定位页面。
- 支持自定义缩放（25%–400%）；支持页面适配的模块可选择「适合宽度」「整页适配」，保留内容比例与留白。
- 普通内容滚轮用于滚动阅读；PDF 另支持显式 Ctrl+滚轮缩放。
- 沉浸阅读支持 F11 进入/切换全屏、Esc 退出；隐藏系统标题栏并覆盖任务栏，边角可唤出工具栏和页码。内容保持比例，不强行拉伸。
- 白天、黑夜和跟随系统主题；窄窗口工具栏按功能组换行。阅读按钮统一为图标，悬停显示用途，按「缩放/页面适配 → 格式专属操作 → 打印 → 沉浸」排列。
- PDF 与文本/代码查询使用可拖动的非模态浮窗，文件上方只保留查询入口；输入及各自已有的选项、结果操作集中在浮窗内，不挤占或重排阅读区。Ctrl+F 打开查询，Esc 或窗口内关闭按钮收起并回到入口；各标签的浮窗互不覆盖。
- 首页首次启动显示“小乖专属软件”烟花介绍，署名 By 仔仔。

## 各文件类型

| 类型 | 支持格式 | 已实现功能 |
| --- | --- | --- |
| PDF | `.pdf` | 连续阅读、随缩放自动双页/单页、页码跳转、文字选择与复制、全文搜索及命中定位、目录、缩略图、密码解锁、临时旋转、打印 |
| Word | `.docx`、`.doc` | 文字、图片、表格和分页预览；表格列宽可临时调整；DOCX 可打印 |
| Excel | `.xlsx`、`.xls`、`.csv`、`.tsv` | Sheet 切换、合并单元格与基础样式、宽表横向查看、列宽调整、单元格定位、冻结行列、虚拟滚动；XLSX/CSV/TSV 可主动基础编辑、撤销/重做、另存副本，XLS 只读 |
| PowerPoint | `.pptx`、`.ppt` | 幻灯片连续查看、页码定位、文字与图片等静态布局预览 |
| 文本与代码 | `.txt`、`.text`、`.log`、`.json`、`.md`、`.xml`、`.js`、`.ts`、`.css`、`.ini`、`.yaml`、`.yml`、`.toml` | 行号、搜索高亮、基础语法着色、编码切换；JSON 格式化与无效内容提示；Markdown 排版预览 |
| 图片 | `.png`、`.jpg`、`.jpeg`、`.webp`、`.gif`、`.bmp`、`.svg` | 适配窗口、原始像素查看、旋转、EXIF 方向纠正、打印 |

### PDF 阅读辅助

- 随缩放自动双页/单页：缩小后同一对页面能完整并排时显示双页，放大后放不下则恢复单页；Ctrl+鼠标滚轮、软件倍率输入/按钮均适用。窗口大小、侧栏宽度、适配和旋转变化也会重新判断。
- 配对顺序为 1–2、3–4，第一页面不单独当封面，奇数末页单独居中。混合横竖/尺寸文档可同时出现单页行和双页行；不拉伸页面、不为双页强行改变用户倍率。
- 切换布局保留当前原始页码与行内阅读位置；双页中的当前页有细边框，可点击任一页选择当前页。搜索、目录/缩略图、上下页、批注及标签/窗口移交继续使用原始页码。演示始终单页；打印、导出 PNG 仍按原页处理。同页文字批注保留，跨页划选不合成跨页批注。

- 搜索支持区分大小写及普通文字/通配符/正则三种明确模式；全篇没有可提取文字时提示疑似扫描件。通配符 `?` 匹配一个字符，`*` 匹配同一行内任意字符；正则使用 JavaScript Unicode 语义，零长度匹配不计入结果。每次最多 50000 命中，表达式最多 512 字符，模式搜索每页超时 1 秒可恢复。
- 目录支持标题过滤，保留匹配章节的父级结构，并显示可解析的目标页码。
- Home/End 跳首末页；Ctrl+= / Ctrl+- / Ctrl+0 放大、缩小、重置；Ctrl+滚轮按 10% 调整（普通滚轮仍用于滚动）；R / Shift+R 顺/逆时针旋转。编辑框中的按键不触发阅读快捷键。
- “演示”按钮 / Ctrl+Shift+P 提供独立整页演示，保持比例、黑底、单页、无控制栏；鼠标左击/空格/右箭头前进，右击/左箭头后退，Esc 退出并恢复原窗口全屏状态、阅读倍率和适配。F11 沉浸阅读保持原行为。

- 放大后按住空格并用鼠标左键拖动，或用鼠标中键拖动，平移页面。
- 缩略图支持小、中、大三档；拖动导航栏边界可调整宽度。
- 目录支持层级折叠，当前章节随阅读页码高亮；缩略图与当前页联动。
- 支持文档内部链接跳页；旋转或适配页面后重新对齐文字和链接。
- 选择文字后在选区旁的图标操作条添加高亮或备注，不再往上方工具栏临时插入按钮；批注列表可跳到对应页面、编辑备注和删除标记，当前页 PNG 导出在批注面板中。
- 批注仅在本次打开文件的会话内保留，切换标签后保留，关闭文件后清空；不写回 PDF；可主动通过保存对话框将当前页批注合成 PNG，备注列在页边，关闭文件后仍清空内存批注。
- 根据 PDF 权限控制打印入口。扫描 PDF 没有文字层时无法文字搜索或划选，目前不提供 OCR。
- 解锁密码只保留在当前文件的内存会话中，用于切换/移交后的预览和允许的打印；关闭最后一个使用它的预览或打印列表后释放，不写入应用设置。

### 表格与文本辅助

- Excel 可输入单元格地址（如 `B12`）定位；保留表头/行号的首行、首列固定开关，不再提供“+行/+列”额外冻结。
- Word 和 Excel 的列宽调整只影响当前预览，不修改源文件；Word 临时列宽在标签闲置卸载后仍保留。
- 文本支持 UTF-8、GB18030、UTF-16 LE / BE 编码查看；长文本按可见行渲染，自动换行高度单独记录，缩放后仍可访问末尾。语法与搜索标记不改变显示的原文或空行。
- 代码着色为辅助阅读，并非完整语言分析。Markdown 表格、引用、代码块适配主题。

### Excel 基础编辑与另存副本

- 默认仍为预览，点击铅笔图标「编辑副本」才启用编辑；编辑时铅笔高亮，再点可切回预览并保留本次修改。双击单元格或按 F2 可直接在单元格内输入；Enter 提交并移到下一行，Tab/Shift+Tab 提交并左右移动，Esc 取消，Alt+Enter 换行。点击其他单元格也会提交，输入无效时保留编辑。
- 编辑工具栏固定按「另存副本/格式 → 撤销/重做 → 复制/粘贴/清空 → 居左/居中/居右 → 插入/删除 → 更多」分组，操作按钮使用图标，鼠标悬停显示名称/可用快捷键。恢复源内容在「更多」中并需确认；插入、删除先展开选择菜单。预览模式仍可另存副本。
- 内容栏采用「单元格名称框 → 取消/确认 → ƒx 内容」布局。名称框输入地址后回车定位并选择；内容默认一行，多行时自动展开。工作表标签位于表格底部，可横向查看完整名称。
- 支持文本、数字、清空、向选中单元格粘贴矩形表格、撤销/重做和恢复源内容。表格聚焦时 Ctrl+Z / Ctrl+Y 撤销/重做；编辑框保留自身的文字撤销行为。以单引号开头可强制文本，超过 15 位的整数保留为文本，避免标识编号丢失精度。
- 右键单元格、行号或列标，提供复制/粘贴、清空、上方/下方插行、左侧/右侧插列和删除当前行/列。「自定义插入」可选择整行或整列、前后方向及数量（每次 1–1000）。行列操作支持撤销/重做；普通样式、合并区域、图片锚点及支持的公式引用随位置调整，引用被全部删除时显示 `#REF!`。暂不提供局部单元格向右/向下移动的插入方式。
- 方向键移动选择，Delete/Backspace 清空，选中后输入字符可开始编辑；Ctrl+C 复制单元格，Ctrl+V 粘贴表格。单元格内的文字选择/粘贴沿用编辑框操作，中文输入法确认不提前提交。
- 编辑和 Enter/Tab 移动保留当前视口，仅目标超出可见区域时少量滚动；主动输入地址定位仍可跳转。已移除编辑操作的常驻说明和成功消息行，错误与未保存状态保留。
- 右键「内容居左/居中/居右」修改当前单元格的水平对齐，可撤销/重做并保存到 XLSX 副本。数字未指定对齐时默认居右，文字默认居左。修改内容、行列移动及跨窗口移交保留已选对齐；CSV/TSV 无法承载该设置，选择对齐后请保存 XLSX。
- 基础公式支持同工作表单元格/区域引用、加减乘除/幂、括号及 SUM、AVERAGE、MIN、MAX、COUNT。软件显示和保存公式表达式，**不计算公式结果**；XLSX 副本请求外部表格软件重新计算。暂不输入跨 Sheet、外部引用或其他函数。
- 「另存副本」必须明确选择位置，可保存整份 XLSX，或只保存当前 Sheet 的 UTF-8 CSV/TSV。当前 Sheet 含公式时请选择 XLSX；CSV/TSV 不承载样式、其他 Sheet 和公式计算结果，公式形态的文本会加文本前缀以避免被再次解释为公式。
- XLSX 在原文件 XML 上修改单元格，保留未修改的样式、图片和其他 Sheet；内容修改清理旧公式缓存。支持水平对齐，不提供字体/边框等其他样式编辑、增删 Sheet 或完整 Excel 计算引擎。仅改对齐保留原单元格内容和已有公式缓存；共享/数组公式等不支持内容改写，合并区只编辑左上角。
- 行列结构调整仅用于可安全处理的普通工作簿。已有基础公式的跨 Sheet 引用会同步移动；含不支持的复杂公式、命名区域、图表/透视表/外部引用，或目标 Sheet 含保护、表格对象、条件格式、验证、特殊绘图等时，在调整前拒绝操作，保留数据与草稿。结构撤销快照参考总额为 64 MB，单次超预算不执行；该额度不是软件总内存上限。
- 不覆盖任何已打开的源文件（含路径别名/硬链接）。保存取消或失败保留草稿；关闭标签、窗口或退出软件时，未保存修改会提示取消或放弃。切回预览、标签闲置卸载和跨窗口移交保留本次草稿；关闭后清空，不提供自动保存或崩溃恢复。
- CSV/TSV 保存仅将当前 Sheet 标记为已保存；其他 Sheet 的修改仍提示未保存。保存后的副本不会替换本次源文件，恢复源内容始终回到最初打开的数据。临时列宽、冻结和缩放不写入副本。
- 单次粘贴最多 10000 个单元格/100 万字符，单元格最多 32767 字符；草稿最多 20000 处修改/1000 万字符，撤销历史最多 100 步并受总量限制。新增行区域最多到第 50000 行（原有更长工作表仍可编辑已有范围），最多 16384 列；副本最多 100 MB。

### 图片查看

EXIF 旋转/镜像方向自动纠正一次；手动旋转后按新的宽高适配。原始像素模式下，大图可从原点完整滚动查看，倍率说明随软件缩放更新。旋转和原始像素选择只保留在当前文件的内存会话；标签闲置卸载后恢复，关闭文件后清空。软件适配可覆盖原始像素模式，沉浸阅读临时适配并在退出后恢复选择。

图片工具栏按原始像素、旋转、打印排列；尺寸与倍率/适配状态集中在页脚。文本的字数/行数也放在页脚，行号开关使用图标，编码选择保留在工具栏。Word/PPT 使用公共阅读控件与底部页码导航，本轮没有新增它们的全文查询能力。

## 单文件与批量打印

打印回执区分已提交到系统队列、用户已取消和驱动提交受阻；异常保留回调原因，仍允许失败后重试/继续后续文件。

支持 **PDF、图片和 DOCX**，暂不提供 DOC、Excel、PPT 和纯文本打印。

- 打印设置为独立非模态窗口，可移动、缩放、放到另一显示器或与预览并排；原文件仍可继续阅读。
- 多个文件汇入同一列表，可添加、拖入、勾选、排序、移除和折叠设置；同一文件 ID 不重复添加。
- 打印机为本批次公共设置，每个文件分别设置纸张、方向、份数、页码、颜色、单双面、缩放和页序。
- 纸张：A3、A4、A5、A6、Letter、Legal；份数：1–99。
- 缩放：适合纸张、实际大小、仅缩小；页序：顺序、逆序、奇数页、偶数页；页码范围支持 `1-3,5`。
- PDF 的“实际大小”不自动缩小；超出可打印区域的内容会居中裁切。纸张示意与实际输出采用相同的比例和裁剪规则。
- 可将当前文件设置复制到全部文件；复制后各文件仍可独立修改。
- 展开文件设置时准备纸张预览；显示首页原始尺寸、总页数和所选纸张尺寸，并提供排版示意。
- 点击文件名可联动原预览；原预览关闭后可重建。
- 一次启动后冻结本批次参数并顺序提交，显示进度和逐文件状态；单项失败显示原因并继续。
- 支持停止后续任务；不能撤回已经进入系统打印队列的任务。打印期间新增的文件待当前批次结束后加入。
- 可打开系统打印机/队列；非 A4 纸张提供兼容性提示，该提示不是打印机能力检测。
- 打印窗口关闭后释放本次列表和设置；系统打印后台缓存由 Windows 与驱动管理。

**打印边界：**「已提交」表示系统接受任务，不代表已出纸。应用传入所选纸张，驱动和纸盒配置仍可能影响实际用纸；纸张、彩色、单双面须由打印机支持。目前排版示意与原始尺寸以首页为主，没有逐页纸张预览、发票自动识别或多张发票拼版功能。屏幕预览缩放不等于打印缩放。

## 性能与资源边界

- 批量打开先获取文件信息，文件内容按需加载，加载任务排队。
- 已加载标签的文件字节使用有限缓存（普通窗口参考 512 MB，PDF 窗口按共同预算调整）；超过预算时淘汰部分缓存，再次访问可能重新读取。该预算不是整个应用内存的硬上限。
- 非激活标签闲置后卸载预览 DOM，保留预算内的文件字节与阅读状态；关闭标签释放其缓存。
- PDF 长文档按可见页绘制并释放离屏画布；避免重复排队和过期绘制，缩略图按需绘制。
- 高倍率 PDF 预览限制单页画布像素（600 万以内），极高倍率可能略显柔和；打印使用独立渲染流程。
- PDF 文字提取与搜索缓存按页数自适应保留 32–128 页，每份缓存参考 4–16 MB；全文搜索仍需扫描页面，耗时取决于文件内容。
- PDF 文档加载去重，同窗口复用解析 worker，正在使用的文档由使用凭据保护；缓存命中只更新访问顺序，不重复计费。缓存参考总额为 384 MB / 8 份文档并按窗口调整，闲置解析文档 30 秒后释放；活动大文件和最低文档份额可超过参考额度，不能据此推断软件总内存。
- 连续缩放、窗口调整合并重绘；正文优先于后台尺寸扫描、搜索与缩略图。文字层和搜索共享自适应 32–128 页的文字提取缓存；清空搜索使旧扫描结果失效。
- 正文、临时位图、缩略图和纸张示意一起计费；PDF 阅读窗口共同参考 4800 万像素，单窗口最多 2400 万。高倍率或多窗口时可能降低预览像素，但保持文档显示比例；打印分辨率不受此额度影响。文字层分片构建，长文档尺寸缓存与增量位置索引减少重复计算。
- 批量打印复用隐藏执行窗口（各文件重新加载独立打印页面），空闲 1.5 秒后关闭；整份 PDF 在分配打印画布前先检查像素预算。不同文件仍分别解析，不表示免除打印渲染。
- 历次实施、测试范围与本机性能观察见 [更新记录](docs/更新.md)，不承诺所有文件按同一比例提速。
- Excel、长文本和 PPT 使用虚拟化减少页面节点；打印设置默认折叠，展开时才准备示意。
- 当前读取限制：TXT、TEXT、JSON、MD、LOG、XML 单文件 5 MB，其他已支持格式单文件 100 MB。多选数量不限制，但总内存与打印速度受电脑和文件复杂度影响。

## 安装与兼容性

提供 Windows x64 安装包和免安装 ZIP；ZIP 需完整解压后运行 `File Preview.exe`。无需额外安装 Office 或其他预览软件。安装包目前未商业签名。

复杂 Office 排版、缺失字体、SmartArt、动画和旧格式可能无法完全还原；默认用于预览，Excel 基础编辑仅另存副本，不写回源文件。其他格式不提供编辑保存。

未实施方向见 [项目规范中的后续计划](docs/规范.md#后续计划)，不视为当前已提供能力。当前打印功能集中列在上文。
