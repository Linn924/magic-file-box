# 更新记录

按版本记录新增、优化与修复的功能。

## 未发布

- 将文件加载提示改为预览内容区中央的转圈图标与文字卡片，适配明暗主题、窄窗口及沉浸模式。
- 统一文件读取、等待解析、解析、准备显示与密码等待状态，支持取消加载、保留标签后重试，以及失败后的重新加载。
- 表格解析转至本机后台任务，多个窗口依次解析；取消时释放对应任务，保留现有资源保护。
- 优化标签切换、缓存重新挂载及取消后的迟到结果处理，避免旧加载覆盖新预览。

## 1.0.8（2026-10-21）

- 新增 DOCX 全文搜索，支持 Ctrl+F、匹配计数、当前高亮及上一处/下一处循环定位。
- DOCX 搜索支持同一段落内跨加粗、斜体文字片段匹配，以及表格、页眉页脚和脚注文字。
- 新增 DOCX 标题目录，按大纲级别和标题样式生成，支持同名标题独立定位、滚动同步及目录开关的会话保留。
- 优化窄窗口和放大后的 DOCX 定位，避免页面左侧裁切和查找浮窗遮挡目标。

## 1.0.7（2026-10-16）

- 修复 JSON、文本和代码搜索命中后未定位到内容的问题，搜索时自动显示首个命中并突出当前匹配。
- 搜索显示当前项和总匹配数，支持上一处/下一处及 Enter、Shift+Enter 循环定位；同一行多处命中分别计数。
- 修复长文件虚拟滚动和长换行行中的搜索定位，快速切换查询时取消旧定位。

## 1.0.6（2026-10-15）

- 调整设置弹窗布局，标题与底部说明固定，滚动条仅位于设置内容区。
- 设置按外观、窗口与文件、打印、软件更新、专属服务分组，点击左侧分组可定位到右侧对应组首。
- 手动滚动时同步高亮当前分组，并优化小窗口、缩放及明暗主题下的布局。

## 1.0.5（2026-10-15）

- 优化软件更新源配置，统一版本下载与问题反馈入口。

## 1.0.4（2026-10-15）

- 新增“打开文件时隐藏主页到托盘”设置，默认每次询问，也可选择始终隐藏或不隐藏。
- 打开文件后的确认框支持记住选择，与关闭主页的行为分别设置；隐藏主页后预览窗口继续使用。
- 更新软件图标，放大主体并缩小四周留白。
- 修正 PDF 缩略图列表的高度计算与滚动定位偏差，避免画布被压缩。
- 优化 PDF 缩略图的异步绘制与失效画布释放。

## 1.0.3（2026-10-15）

- 软件更名为“魔法文件匣 / magic file box”，更换应用图标。
- 新增专属 KEY 设置，支持离线签名激活、恢复标准服务，确认后重启生效。
- 修复关闭设置后仍残留“当前已是最新版本”提示的问题。
- 优化模块、公共组件、工具和样式的职责划分，统一通用打印能力。
- 保留原应用设置目录与文件关联的兼容性。

## 1.0.2（2026-10-14）

- Excel 新增区域升降序与多列排序，支持最多八列优先级、稳定排序和空值置后。
- Excel 新增按显示值和空值筛选，支持列内多值、跨列组合、重新应用及清除条件。
- 支持复制和 CSV/TSV 导出可见行；XLSX 可保存完整数据与筛选条件。
- 排序时关联移动同行数据、样式、行高与手动隐藏状态，并调整支持的公式引用；支持整组撤销与重做。
- 修复自定义 CSS 弹窗无法正常滚动、内容伸入页脚以及窄窗口预览遮挡输入框的问题。

## 1.0.1（2026-10-14）

- Excel 新增工作表的新建、重命名、复制、删除、顺序调整、隐藏与取消隐藏。
- 工作表管理支持名称校验、删除确认和最后一个可见工作表保护。
- 工作表操作保留常见内容、样式、尺寸、合并单元格、图片、超链接和备注，并调整支持的公式引用。
- 工作表管理接入撤销、重做、恢复源内容与另存副本流程。
- 优化首页界面，移除多余署名。
