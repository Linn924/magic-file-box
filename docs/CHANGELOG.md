### 实施结果与参数

上述必要修复与值得优化项在同一批实现，不保留为下一轮待办：

- 读取/引用：`electron/files.ts` 负责合并读取、AbortSignal、完整 backing buffer、窗口/打印列表引用和会话密码；`transfers.ts` 在移交确认时先保留目标引用再关闭来源。原始字节缓存命中更新 LRU。未激活标签不启动解析。
- 解析/缓存：`docCache.ts` 使用凭据、并发去重、共享 worker、30 秒闲置回收；构造异常、加载中关闭、密码替换都会释放，活动文档保持独立 transport。
- 预算：主进程 `pdfResources.ts` 为已注册 PDF 窗口分配参考额度：画布总额 4800 万像素、单窗口最多 2400 万；源字节参考总额 384 MB，解析缓存与字节缓存各自计费；闲置文档参考总额 8 份，单窗口至少一份。活动大文件、最低文档份额、预算变化中的正在执行任务属于必要例外，不是整个软件的硬内存上限。
- 位图：`canvasPool.ts` 跟踪正文、缩略图、示意与临时位图；显示与离屏画布同时计费，滑出、替换、隐藏和关闭显式释放。正文仍有单页 600 万像素限制，长边再限制为 8192 像素；资源不足时保留 CSS 比例并降低预览像素。
- 文字/搜索：共享最多 32 页、估算 4 MB 的 TextContent 缓存；搜索字符串最多 32 页、约 2 MB（必要单页可超）。每 200 项提交一批 DOM，复用字体测量状态，应用 viewport 与文字矩阵。命中仅存页码/原始偏移/长度，非响应式逐条数据在批次末通知，界面只接收计数；保留所有命中，不复制无用摘要。清空与切换查询取消旧结果、解绑高亮，迟到定位无效。
- 布局：`pageIndex.ts` 增量前缀树使尺寸修正/定位为 O(log N)，缩放或真正影响适配的尺寸变化再整体重建；仅预算改变不重建文字层。页面尺寸共享缓存，后台优先阅读附近、每批最多 64 页。批注按页索引，编辑合并保存，并在卸载前保留最后状态。
- 打印：`print/rasterPlan.ts` 为示意与输出共用比例/裁剪算法；打印仍是 150 DPI、每份最多 6000 万计划像素，实际大小不再被 CSS 缩小；独占任务字节直接交给 worker。隐藏执行窗口复用但每份重新加载独立页面；每任务 UUID、consume 标志与回调身份检查，拒绝迟到/重复通知，失败销毁、闲置 1.5 秒释放。
- PDF 打印使用 PDF.js 的 print intent，完成栅格与字体准备后直接进入原生打印布局，不再等待隐藏窗口中的两次动画帧。图片/DOCX 既有路径保留并回归，打印分辨率不因此降低。

以上辅助逻辑均留在 PDF 模块；跨类型读取、窗口移交和打印契约留在共享/主进程层，App.vue 没有新增格式解析分支。

### 暂不改动及理由

- 不切换 PDF.js、Electron 或矢量打印引擎：属于兼容性重构，需要更多设备验收；本轮保持 150 DPI 与现有纸张行为。
- 不使用 worker 间共享可写字节或关闭隔离来追求“零复制”：安全和兼容性代价大，IPC/worker 的必要副本明确保留。
- 不自动拆分打印作业：会影响份数、双面与逐份装订语义；保留预算拒绝及用户指定范围。
- 不新增 OCR、双页视图或批注导出：属于功能扩展，不混入性能任务。
- 不承诺任意数量窗口下的整个软件内存硬上限：源文档解码、Electron 基础进程和驱动内存不能只靠画布预算控制。

### 交付边界（本轮明确保留）

- 合成样例覆盖数量/结构与生命周期，不代表全部真实文档、字体、复杂扫描图或驱动。开窗单次、100 ms 断言轮询与固定缩放观察等待不是精确的交互逐帧分布；工作集不是总 GPU 显存或完全瞬时峰值。
