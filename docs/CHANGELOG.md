# 更新记录

按版本记录新增、优化与修复的功能。

## 未发布

- PDF 搜索改用独立解析会话分批提取文字，按页数和读取量释放并重建搜索 Worker，避免全文扫描耗尽阅读会话的累计读取预算。
- 搜索失败时保留已找到的全部结果和定位能力，并明确标注未完成；清空、换词和关闭文件取消旧搜索并释放资源，正常阅读不退出。
- 修复保留搜索结果时正文重绘可能滚回旧命中的问题，主动翻页和滚动后不再抢回阅读位置。
- 修复拖动 PDF 缩略图侧栏宽度或切换尺寸后滚动位置落到错误页面的问题，保留当前可见页及页内位置。
- 托盘右键菜单新增“设置”，恢复主页并打开设置面板，保持其他预览窗口的显示状态。

## 1.0.20（2026-10-26）

- 修复点击 PDF 缩略图时侧栏被当前页同步再次定位、导致列表突然跳动的问题；鼠标和键盘选择保留列表位置，正文翻页仅在缩略图不可见时按需滚动。

## 1.0.19（2026-10-26）

- 统一普通按钮、图文按钮和工具栏按钮的文字与图标居中，修复自定义按钮上下内边距及字符图标的基线偏移。
- 统一输入框和下拉框的垂直对齐与明暗主题状态，区分可编辑、只读和禁用控件，保留长名称的省略显示。
- 应用内弹窗增加从中心展开、收拢为细线后消失的开合效果；右下角通知从右侧滑入、向右滑出，其他卡片平滑补位，支持减少动态效果。
- 修复关闭预览窗口后立即点击打印列表时，重新打开预览的请求可能丢失的问题。
- 修复高缩放下 PDF 目录自动定位可能将选中行贴边裁切的问题。

## 1.0.18（2026-10-23）

- 将各类文件的预览限制与兼容性说明移到右下角“预览提示”，支持手动关闭和文件会话内记忆；与更新通知排列显示，不再占用工具栏和正文空间。
- 新增“消息通知”设置，可选择一直显示或 5 秒后自动关闭，两种模式都支持手动关闭。
- 修复通知关闭图标未居中及多条通知叠放时的背景、阴影问题。
- 文件格式、代码语言和统计信息集中到顶部文件信息栏，移除文本与图片的底部状态栏，保留页码、工作表及分段导航。

## 1.0.17（2026-10-23）

- 切换标签后继续后台加载并保留计时；已完成预览按内存压力释放，取消固定两秒卸载，保留阅读状态与 Excel 草稿。
- 优化加载中跨窗口拖拽的移交与资源释放，并修复拖拽后台标签时阅读位置可能被隐藏页面滚动值覆盖的问题。
- 文件加载提示统一为“正在加载…”，隐藏读取、解析及准备显示等内部阶段；超过 3 秒显示耗时，等待达到 10 秒才显示“重新加载”，移除取消加载按钮，可直接关闭文件标签。

## 1.0.16（2026-10-23）

- 修复 Excel 反向范围引用的部分剪切可能漏过安全检查的问题，失败时保留全部原数据与公式。
- 修复删除反向引用范围的端点后生成无效单元格地址的问题，并完善反向范围的行列上限校验。
- 修复大工作簿从较后列组切换到较窄工作表时显示空白的问题，新工作表从首列显示。

## 1.0.15（2026-10-23）

- 修复 Markdown 源码内嵌较短代码围栏时的折叠范围错误，代码块内的示例标题不再影响外部章节折叠；支持未闭合围栏折叠至文末。
- 修复图片 EXIF 曝光时间的小数值被错误取整的问题，0.75 秒等曝光时间按原数值显示。

## 1.0.14（2026-10-23）

- 修复 PDF 目录书签位置不准确、父子章节共用坐标时点击子标题不能靠近阅读区顶部的问题；使用唯一匹配的完整标题校正跳转和滚动选中位置。
- 修复跳到较短的最后一页时，目录因页面无法顶齐视口而误选上一章节的问题。
- 修复 PDF 内部链接引用不存在的页面时产生未处理异常的问题，保留当前阅读位置，后续有效链接仍可使用。
- 修复 PDF 网页链接无法打开系统浏览器的问题，保持沙箱隔离，并在主进程校验 HTTP/HTTPS 协议。

## 1.0.13（2026-10-23）

- PDF 目录支持页内精确定位，同页不同章节可分别跳转，正文滚动时按章节位置同步选中项。
- 文本与代码新增跳行、语法结构折叠和全部展开/折叠，搜索及跳行可展开被隐藏的目标行。
- 源码搜索改为可取消的分批处理，减少连续输入与重复匹配高亮对界面的阻塞，保留完整匹配计数和定位。
- 图片新增常见 EXIF 信息查看与颜色取样，支持旋转后的 HEX/RGB/透明度及坐标，大图片明确标记预览像素。

## 1.0.12（2026-10-22）

- 优化打印输入框和下拉框的明暗主题配色，区分可编辑、聚焦和禁用状态。

## 1.0.11（2026-10-22）

- PDF 目录标题改为单行显示，超出宽度显示省略号，悬停可查看完整标题，并保留页码显示。
- PDF 目录搜索栏与条目滚动分离，避免标题滚到搜索栏后方；折叠控件改为紧凑三角箭头，修复有无子级时同级标题错位。

## 1.0.10（2026-10-22）

- 修复软件更新说明直接显示 HTML 列表标签的问题，按分行文字显示条目和段落。

## 1.0.9（2026-10-22）

- 新增大文本、JSON、CSV/TSV 分块预览，支持编码切换、记录定位、分段查找及取消读取。
- 大 PDF 按需读取文件范围；大图片提供像素检查和缩小预览。
- 大型 XLSX、DOCX、PPTX 支持按工作表、正文段落和幻灯片查看主要内容，内嵌图片按需显示；界面说明此模式的排版、编辑与输出边界。
- 支持按需读取的格式取消原 5 MB / 100 MB 文件门槛，保留读取、解压、像素和并发保护。
- 将文件加载提示改为预览内容区中央的转圈图标与文字卡片，适配明暗主题、窄窗口及沉浸模式。
- 统一文件读取、等待解析、解析、准备显示与密码等待状态，支持取消加载、保留标签后重试，以及失败后的重新加载。
- 表格解析转至本机后台任务，多个窗口依次解析；取消时释放对应任务，保留现有资源保护。
- 优化标签切换、缓存重新挂载及取消后的迟到结果处理，避免旧加载覆盖新预览。

## 1.0.8（2026-10-21）

- 新增 DOCX 全文搜索，支持 Ctrl+F、匹配计数、当前高亮及上一处/下一处循环定位。
- DOCX 搜索支持同一段落内跨加粗、斜体文字片段匹配，以及表格、页眉页脚和脚注文字。
- 新增 DOCX 标题目录，按大纲级别和标题样式生成，支持同名标题独立定位、滚动同步及目录开关的会话保留。
- 优化窄窗口和放大后的 DOCX 定位，避免页面左侧裁切和查找浮窗遮挡目标。

## 1.0.7（2026-10-16）

- 搜索显示当前项和总匹配数，支持上一处/下一处及 Enter、Shift+Enter 循环定位；同一行多处命中分别计数。
- 修复长文件虚拟滚动和长换行行中的搜索定位，快速切换查询时取消旧定位。
